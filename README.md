# JutsuNexus – download site

Static site (GitHub Pages) with the Android download, install guide (Hebrew, English under `en/`) and feature overview.
The APK itself is not in this repo: it is a GitHub Release asset named `JutsuNexus.apk`, so the download button
always points at `releases/latest/download/JutsuNexus.apk`.

New version: publish a release with the new `JutsuNexus.apk` attached, then update the version text in
`index.html` and `en/index.html` (hero `.meta` line and footer).
